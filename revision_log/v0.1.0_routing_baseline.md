# v0.1.0 Routing Baseline

## Date

2026-05-10

## Author

Codex

## Summary

Created the first GitHub-ready baseline for a point-to-point map routing web application.

## What Changed

- Initialized a React, TypeScript, Vite frontend.
- Added Leaflet and React Leaflet map rendering with OpenStreetMap tiles.
- Added click-to-select start and target locations.
- Added route alternative drawing and route summary display.
- Added a FastAPI backend with `/api/health` and `/api/routes`.
- Added OSRM public demo route fetching and response normalization.
- Added backend and frontend tests.
- Added design, implementation plan, README, changelog, and revision index.
